<h1 align="center">Hey, I'm Thruqe</h1>

## About
I'm an engineering student with a focus on backend systems that need to hold up under real load. My work centers on Go and Rust, with TypeScript when the project calls for it. Alongside that, I do reverse engineering, and I've contributed to automation and WhatsApp-client projects, including work around [WhiskeySockets/Baileys](https://github.com/WhiskeySockets/Baileys).

I run [ThruqeLabs](https://github.com/ThruqeLabs), a team building automation tools and infrastructure. [whatsrook](https://github.com/ThruqeLabs/whatsrook) is one of ours.
